## 中心となる利用の流れ

在庫が減る → 買い物リストへ追加 → 担当・店舗・商品を選ぶ → 購入済みにする → 在庫を補充する。

家庭ごとのデータ分離、家族への招待、退出後のアクセス停止、買い物と在庫の整合性を重視します。

## GitHubへの保存について

Mac上の変更をGitHubに送るには、Mac側でコミットとプッシュを実行する仕組みが必要です。GitHub Actionsは、送信後のコードに対する検査などに使います。

`.gitignore` は環境変数の実値、鍵、依存関係、キャッシュ等を除外するための初期設定です。既にGitで追跡中のファイルを自動で非公開にしたり、秘密情報の混入を完全に検出したりする機能ではありません。実ソース受領後に構成に合わせて確認します。
